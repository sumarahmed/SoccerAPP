# ACT-SP-077-02 — Paired F01–F33 state inventory

Version `1.0-review-ready` is represented by `contracts/design/sp007-sp038-screen-states.json` and the interactive HTML review handoff.

All 33 frames are required in Light and Dark, portrait and applicable landscape/desktop layouts. F23–F33 add billing, promotions, sync, Appearance, MFA, guardian authority, player-device handoff, private web/media access, export/share, safety/help, and data-rights states. Follow device is the default; a system change updates the active theme unless the adult has explicitly selected Light or Dark.

The prototype is a design-state handoff, not a working application. It demonstrates state coverage and copy but does not claim native-device, screen-reader, touch-target, or runtime visual-regression testing.
