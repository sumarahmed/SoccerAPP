# ACT-SP-153-02 — Comparability and correction history

Two results are comparable only when protocol/version, setup, equipment, surface, assistance, observation source, and applicable foot/side match. A changed condition remains a valid standalone result when safe, but is labelled not comparable. Missing required fields, unsafe conditions, or an unobservable attempt produce no result.

No video is a normal state and does not invalidate a sufficiently observed result. Corrections append a timestamped replacement value, author/source, and reason; the prior value remains in history and is not silently overwritten.
