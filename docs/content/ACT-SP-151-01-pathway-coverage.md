Age suitability and assessed ability are separate gates. Older beginners receive the same neutral labels and coaching cues; the UI must not use childlike or remedial language. Completion records practice only and never raises assessed ability.

An offered path must contain an eligible start, ordered steps, and a next step. A missing, withdrawn, unapproved, or superseded variant blocks the affected path. The catalogue can grow after separate review; ten is the initial release size, not an authoring limit.
